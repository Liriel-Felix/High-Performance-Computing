# IMD1116 - Computação de Alto Desempenho (UFRN)

Esse repositório reune códigos e relatórios da disciplina de Computação de Alto Desempenho ministrada pela dra. Carla Santana, com foco em:
- Noções de programação paralela, concorrente e distribuída;
- Computação em nuvem e supercomputação;
- Arquiteturas de hardware para computação de alto desempenho no contexto de aprendizado profundo.

## Avaliações

- 1º e 2º Unidade
    - **20% Envio do código das tarefas dentro do prazo** + relatório;
        - Código deverá ser enviado em pdf via SIGAA até meia noite do próximo
        dia
    - **80% Avaliação Oral**
        - Envio de um documento único (em pdf) com os relatórios de todas as
        tarefas da unidade até o dia anterior da avaliação oral
        - Cada relatório deve conter:
            - Enunciado da tarefa
            - Código fonte desenvolvido
            - Análises e gráficos solicitados na tarefa
            - Esse relatório servirá como base para que o estudante realize a
            defesa da tarefa.
- 3º Unidade
    - Projeto final em grupo

## Organização do repositório
Cada pasta corresponde a uma tarefa da disciplina e conterá:
- Código-fonte desenvolvido em C;
- Relatório em formato .md;
- Versão final do relatório em .pdf.
